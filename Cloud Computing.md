In traditional host work, we host the files , code and data into our system like computer or laptop in local but our system is very limited storage and ram so for add more web services is not possible.
So  there is **Cloud computing** use we can host our web services file , data on on Cloud providing system. Ram , storage , system , network every things can handle by the cloud providers.

## Benefits of Cloud hosting 

- User friendly : There in know need knowledge about system and technical things to host in cloud.

-  Speed : Cloud provide high speed network and Content Delivery Network ( CDN )
   so web service response is very fast and very limited network issues should be have that will troubleshoot very fast and also dedicated IP address.

-  Scalability : You can easily upgrade your plan to get more CPU cores, RAM, and storage space in just a few clicks.

-  Greate security: advanced DDoS protection, your site will be less prone to security issues and cyber threats. We also provide automatic daily backups to keep your data safe

## Conclusion 
Cloud hosting is essentially a faster, stronger, and more secure alternative to shared hosting.
